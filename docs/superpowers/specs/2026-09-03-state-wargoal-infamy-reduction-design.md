# 地区战争目标恶名减免设计

日期：2026-09-03

## 目标

在 Victoria 3 1.13.11、Tech & Res 1.6、Firefall 0.1.1 与本 Mod 的最终加载数据库中调整两个原版战争目标：

- `conquer_state`：恶名计算值减少 15%；
- `return_state`：恶名计算值减少 30%。

保留原版最低恶名：征服地区最低 5，归还地区最低 2。因此最终公式分别为：

- `max(原版征服恶名 × 0.85, 5)`；
- `max(原版归还恶名 × 0.70, 2)`。

## 实现边界

加载顺序为：原版 → Tech & Res → Firefall → 本 Mod。当前安装版本中，Tech & Res 与 Firefall 均未修改这两个战争目标，最终上游基线为原版 1.13.11。

新增一个 `common/war_goal_types` 文件，以 `INJECT:` 只接管 `conquer_state` 与 `return_state` 的 `infamy` 子表。两个子表以原版 1.13.11 为基线完整重述，仅在原版 `min` 之前增加对应倍率。其余战争目标字段继续由原版和上游拥有。

为两个倍率添加英文和简体中文计算提示，两份本地化保持相同键集合。

不修改：

- 全局恶名倍率或国家 modifier；
- 外交博弈、战争目标有效性和 AI 战略；
- 统一战争的独立恶名规则；
- on_action、事件、持久变量或存档接口。

## 生命周期与兼容性

该调整直接作用于战争目标数据库，新游戏和旧存档均无需迁移。原版战争目标定义更新后，需要重新比较两个 `infamy` 子表；Tech & Res 或 Firefall 日后开始覆盖这两个子表时，也需要按最终加载顺序重新合并。

## 验证

- 检查两个 `INJECT:` 顶层键和 `infamy` 子表结构；
- 对比原版 1.13.11，确认除新增倍率外无公式差异；
- 检查倍率位于原版 `min` 之前；
- 验证英文与简体中文键集合一致、无重复且保留 BOM；
- 运行 `git diff --check`；
- 运行时分别检查高于最低值和触发最低值的征服/归还战争目标预估恶名。
